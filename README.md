# Ansar Market

Веб-сайт небольшого продуктового магазина у дома. Проект предназначен для удобного просмотра ассортимента товаров, цен и актуальных предложений.

## Структура проекта

```text
ansar-market/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── images/
│   └── Фотографии товаров
└── README.md
```

## Технологии

- HTML
- CSS
- JavaScript

## Основные возможности

- Просмотр товаров
- Каталог продукции
- Цены на товары
- Актуальные скидки
- Удобный интерфейс
